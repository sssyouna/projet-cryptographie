System Overview

This OAuth2 system consists of three main components:

  1. Authorization Server (Omar) - Issues and manages JWT tokens
  2. Resource Server (Your Implementation) - Validates tokens and serves protected resources
  3. Client Application (Badr) - Consumes the API using valid tokens
